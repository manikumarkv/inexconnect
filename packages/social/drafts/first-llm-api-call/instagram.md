## Carousel slides

Design in the brand template (coral #FF5C50, one idea per slide, big type).

- Slide 1 (cover): Your first LLM API call
- Slide 2: An LLM API call is an HTTPS request with JSON inside. You send a list of messages, and the model sends back one new message.
- Slide 3: Keep your API key in an environment variable or a git-ignored .env file. Never put it in your code or commit it.
- Slide 4: The response tells you why the model stopped (stop_reason) and how many tokens it used (usage). Tokens are what you pay for.
- Slide 5: The API remembers nothing between calls. To hold a conversation, your code sends the whole history every time.
