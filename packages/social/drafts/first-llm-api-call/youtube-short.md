- [3–18s · POINT 1] An LLM API call is an HTTPS request with JSON inside. You send a list of messages, and the model sends back one new message.
- [18–33s · POINT 2] Keep your API key in an environment variable or a git-ignored .env file. Never put it in your code or commit it.
