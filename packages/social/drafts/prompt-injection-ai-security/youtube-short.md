## Script (~111 words — aim for 130–150)

Record as screen capture + face cam or voiceover. Put each point on screen as big text.

- [0–3s · HOOK] Prompt injection and AI security: what developers need to know
- [3–18s · POINT 1] Prompt injection is text that tries to give your AI new instructions. It can come from the user (direct) or from content the AI reads, like a web page or an email (indirect).
- [18–33s · POINT 2] A model reads instructions and data as the same kind of text, so it can't reliably tell them apart. There is no known way to prevent injection completely.
- [33–48s · POINT 3] The damage depends on what the AI can do. Tools, agents and MCP servers that act on your systems raise the stakes.
- [~50s · CTA] The full guide is on our blog — link in the description. Follow for more AI dev tips.
