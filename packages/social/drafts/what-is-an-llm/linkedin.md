What is an LLM? Here's the short answer.

An LLM is the engine behind ChatGPT and Claude. Learn how it writes text, what tokens and context windows are, and why it sometimes makes things up.

Key takeaways:
→ An LLM (large language model) is a program trained on a huge amount of text. It writes by predicting the next token, again and again.
→ Tokens are small pieces of text. Models read, write, limit and bill everything in tokens.
→ The context window is the model's working memory. Anything outside it, the model can't see.
→ LLMs can sound sure and still be wrong. Give them the facts they need and check important answers.

Q: Is ChatGPT an LLM?
A: ChatGPT is an app built on top of LLMs from OpenAI. In the same way, the Claude apps are built on Anthropic's Claude models. The chat app adds the window you type in; the LLM writes the answers.
