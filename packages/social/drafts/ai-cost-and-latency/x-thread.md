AI cost and latency: what drives them and how to cut them 🧵👇

### Post 2 (154/280)

1/ Cost is tokens in times the input price plus tokens out times the output price. Output tokens cost five times more than input on current Claude models.

### Post 3 (148/280)

2/ Latency comes mostly from model size and how many tokens the model must read and write. Time to first token and total time are different numbers.

### Post 4 (131/280)

3/ The biggest levers are the smallest model that passes your evals, shorter prompts and answers, prompt caching and the Batch API.

### Post 5 (106/280)

4/ Streaming doesn't make a request cheaper or finish sooner, but users see the answer start much earlier.
