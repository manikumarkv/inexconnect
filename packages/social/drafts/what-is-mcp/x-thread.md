What is MCP? Here's the short answer. 🧵👇

### Post 2  (128/280)

1/ MCP (Model Context Protocol) is an open standard that lets AI apps like Claude and ChatGPT connect to outside tools and data.

### Post 3  (111/280)

2/ An MCP server wraps one system, such as GitHub, a database or your docs, and any MCP-capable app can use it.

### Post 4  (111/280)

3/ Find servers in the official MCP Registry, the Anthropic Directory, or the docs of the tool you already use.

### Post 5  (99/280)

4/ In Claude Code, one command connects a server; the AI then calls it when your question needs it.
