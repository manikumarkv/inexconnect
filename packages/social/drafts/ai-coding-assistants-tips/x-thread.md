Getting the most out of AI coding assistants 🧵👇

### Post 2  (148/280)

1/ An AI coding assistant is only as good as the context you give it, so write your project's rules down once in a file like CLAUDE.md or AGENTS.md.

### Post 3  (95/280)

2/ Ask for one small, clear task at a time, with the goal, the limits and the files to look at.

### Post 4  (120/280)

3/ Give the assistant a check it can run, such as your tests, and ask it to show the result instead of saying it's done.

### Post 5  (97/280)

4/ Read every line of AI-written code before you merge it, and never paste secrets into a prompt.
