- Slide 1 (cover): How to build your own blog with Astro and Keystatic
- Slide 2: Astro builds the site into plain HTML files. Keystatic gives you an admin screen at /keystatic that saves each post as a file in your repo.
- Slide 3: Your posts live in git, so you get history, pull requests and reviews for free, and you need no database.
- Slide 4: Describe each post field twice, in keystatic.config.ts for the editor and in Astro's content schema for the build, so bad content fails the build.
- Slide 5: Keystatic's local mode only runs on your machine. Use GitHub mode when you want to write on the live site.
