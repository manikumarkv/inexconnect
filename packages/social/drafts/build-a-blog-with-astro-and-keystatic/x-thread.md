### Post 1  (54/280)

How to build your own blog with Astro and Keystatic 🧵👇

### Post 2  (142/280)

1/ Astro builds the site into plain HTML files. Keystatic gives you an admin screen at /keystatic that saves each post as a file in your repo.

### Post 3  (108/280)

2/ Your posts live in git, so you get history, pull requests and reviews for free, and you need no database.

### Post 4  (149/280)

3/ Describe each post field twice, in keystatic.config.ts for the editor and in Astro's content schema for the build, so bad content fails the build.

### Post 5  (109/280)

4/ Keystatic's local mode only runs on your machine. Use GitHub mode when you want to write on the live site.
