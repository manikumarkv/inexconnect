## Carousel slides

Design in the brand template (coral #FF5C50, one idea per slide, big type).

- Slide 1 (cover): AI agents vs MCP
- Slide 2: MCP and agents are not alternatives. MCP is a protocol for connecting tools and data to AI apps. An agent is a way of running a model in a loop that uses tools.
- Slide 3: Tool calling is the model's ability to ask for a tool. MCP is one way to supply those tools. An agent is the loop that keeps calling them until the task is done.
- Slide 4: An agent can use tools from MCP servers, built-in tools, or both. An MCP server works with any MCP app, agent or not.
- Slide 5: Ask two questions - does the task need many steps the model must choose? That's an agent. Do the tools already exist as MCP servers, or should they be reusable? That's MCP.
