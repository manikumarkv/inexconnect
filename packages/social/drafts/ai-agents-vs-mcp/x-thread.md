### Post 1 (68/280)

AI agents vs MCP: what's the difference and how they fit together 🧵👇

### Post 2 (163/280)

1/ MCP and agents are not alternatives. MCP is a protocol for connecting tools and data to AI apps. An agent is a way of running a model in a loop that uses tools.

### Post 3 (164/280)

2/ Tool calling is the model's ability to ask for a tool. MCP is one way to supply those tools. An agent is the loop that keeps calling them until the task is done.

### Post 4 (120/280)

3/ An agent can use tools from MCP servers, built-in tools, or both. An MCP server works with any MCP app, agent or not.

### Post 5 (175/280)

4/ Ask two questions - does the task need many steps the model must choose? That's an agent. Do the tools already exist as MCP servers, or should they be reusable? That's MCP.
