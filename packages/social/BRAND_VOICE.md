# iNexConnect brand voice (for the marketing agents)

Every agent reads this before writing. The brand reviewer checks against it.

## Who we are

iNexConnect LLC — a Dallas–Fort Worth software studio. We build mobile apps,
web apps and websites, use the latest AI tools to build faster, and build AI
into the products we ship (MCP servers, agents, AI integration). Tagline:
**Idea • Build • Grow**.

## Who we talk to

1. **Developers** learning practical AI (MCP, agents, RAG, Claude Code).
   They follow us for clear, hands-on explanations.
2. **Founders and business owners** who need an app, a website or AI in their
   product. They hire us after seeing we know what we're doing.

Teaching content earns trust from both. Sell softly: one call to action per
post, never a hard pitch.

## How we sound

- **Plain English.** Short sentences. Explain jargon the first time.
- **Practical.** Every post gives the reader something they can use today.
- **Calm and honest.** No hype, no "game-changer", "revolutionary",
  "unlock", "supercharge", "in today's fast-paced world", "let's dive in".
- **Specific.** Real tool names, real steps, real numbers — only ones that
  appear in the source blog post. Never invent stats, quotes or results.
- **Respectful of risk.** Where the post mentions safety (secrets, prompt
  injection, approvals), keep that caveat.

## Formatting rules

| Platform      | Length                                                              | Emojis         | Hashtags                   | Link                       |
| ------------- | ------------------------------------------------------------------- | -------------- | -------------------------- | -------------------------- |
| LinkedIn      | 120–250 words; first line ≤ 15 words and earns the "see more" click | 0–2            | 3–5 at the end             | in the post                |
| X             | thread of 3–7 posts, each ≤ 280 chars (links count as 23)           | 0–1 per post   | 1–2, last post only        | last post                  |
| Instagram     | caption ≤ 150 words; 4–8 carousel slides, ≤ 25 words a slide        | 1–3            | 8–12 at the end            | "link in bio"              |
| YouTube Short | ≤ 60 s, 130–150 spoken words, 5–8 on-screen scenes                  | none on screen | 3 + #Shorts in description | description                |
| YouTube long  | 8–15 min; full narration script                                     | none           | 3 in description           | description, first 2 lines |

## Links and calls to action

- Always use the UTM link already in the draft (`utm_source=<platform>`).
- Teaching posts → "Full guide: <blog link>".
- Service-adjacent posts (AI integration, MCP servers, apps) may add:
  "Need this built? Book a free discovery call: https://inexconnect.com/book".
- Contact email: hello@inexconnect.com.

## Visual style (for carousel, thumbnail and Short specs)

- Brand colors only: charcoal `#232323`, coral `#FF5C50`, white, mist `#F7F7F8`.
- Wrap 1–2 key words per slide in `**double asterisks**` to highlight them in coral.
- One idea per slide or scene. Big type beats more words.
- Thumbnail: ≤ 4 words, uppercase is applied automatically.
